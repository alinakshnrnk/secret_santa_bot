# Telegram-бот «Тайный Санта»

## Возможности первой версии
- Создание игр только пользователями из `ADMIN_IDS`
- Несколько независимых игр
- Приглашение участников по deep link
- Анкета участника: имя, пожелания, ссылка на вишлист
- Бюджет и дедлайн игры
- Тайная жеребьёвка без назначения самого себя
- Личные сообщения участникам
- Напоминания за 3 и 1 день до дедлайна

## 1. Создай Telegram-бота
1. Открой Telegram и найди `@BotFather`.
2. Отправь `/newbot`, задай имя и username.
3. Скопируй токен. Не публикуй его в GitHub и не отправляй посторонним.

## 2. Узнай свой Telegram user ID
Напиши боту `@userinfobot` или используй другой проверенный способ узнать свой числовой Telegram ID.

## 3. Запуск на компьютере (Windows)
Установи Python 3.12.
Открой терминал в папке проекта и выполни:

```bash
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Скопируй `.env.example` в `.env`, заполни значения. Для локального запуска установи переменные окружения вручную либо используй PowerShell:

```powershell
$env:BOT_TOKEN="токен_от_BotFather"
$env:ADMIN_IDS="твой_telegram_id"
$env:DEFAULT_BUDGET="1500"
$env:DB_PATH="santa.db"
python bot.py
```

## 4. Команды
- `/start` — приветствие или вход в игру по приглашению
- `/newgame` — создать игру (только организатор)
- `/games` — список игр организатора
- `/draw TOKEN` — провести жеребьёвку конкретной игры
- `/cancel` — отменить текущий ввод

## 5. Размещение на Render
1. Создай приватный GitHub-репозиторий и загрузи туда `bot.py`, `requirements.txt`, `render.yaml`, `README.md`.
2. В Render выбери **New + → Blueprint** и подключи репозиторий.
3. Render прочитает `render.yaml` и создаст Background Worker с постоянным диском.
4. В настройках Environment добавь:
   - `BOT_TOKEN` — токен от BotFather
   - `ADMIN_IDS` — твой Telegram user ID
5. Убедись, что диск смонтирован в `/var/data`, затем запусти деплой.

Важно: постоянный диск Render доступен на платных планах. Без persistent disk SQLite-файл может потеряться при перезапуске или новом деплое. Перед реальным запуском проверь доступность дисков и тарифы Render.

## Важные ограничения MVP
- Для личных сообщений каждый участник должен хотя бы один раз открыть бота и нажать Start.
- Организатор не получает таблицу соответствий — бот не раскрывает пары.
- Если участник заблокировал бота или не запускал его, отправка результата ему не удастся. В этой первой версии жеребьёвка всё равно фиксируется; перед настоящей игрой стоит добавить проверку доставки и безопасный повтор отправки.
- Сейчас исключения между конкретными людьми и ручное редактирование участников не реализованы.
